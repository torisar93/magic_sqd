# FAW Bestune (B70, T77, T90, T99)

## T90 — отдельный ПОДРОБНЫЙ пост найден (другой путь — не инженерное
меню, а через AndroidAuto-бокс!)
https://www.drive2.ru/l/731709596195889420/ ("Установка приложений. Пример
подключения устройства Carlinkit TBox") — НЕ СЧИТАН ПОДРОБНО в этом
заходе, но заголовок говорит о принципиально другом методе: через
беспроводной адаптер CarPlay/Android Auto (Carlinkit TBox), а не через
штатное инженерное меню/ADB. Это стоит проверить отдельным WebFetch —
может оказаться значительно ПРОЩЕ для конечного пользователя, чем
инженерное меню.

## T77 — общий метод (частично)
Источники: https://www.drive2.ru/l/655872156059568497/ (CarPlay),
https://www.drive2.ru/l/655311405129409510/ (FAQ по T77, не считан
подробно).
Вход в инженерное меню — ОДИН ИЗ ДВУХ способов (сводка поиска, точный
источник фразы не зафиксирован):
- Одновременно зажать 3 кнопки: голос + радио + телефон.
- ИЛИ через раздел "информация о системе" → тапнуть по значку
  восклицательного знака несколько раз.
После входа — тумблер "setting ADB" → включить USB debug режим.
⚠️ Сводка поиска предполагает, что этот метод, ВОЗМОЖНО, общий для всей
линейки (B70, T90, T99), но ТОЧНЫЕ пароли/коды НЕ найдены ни для одной
модели — это только гипотеза по аналогии, требует подтверждения.
