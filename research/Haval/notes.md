# Haval (Dargo, F7×2, H3, H5, H7, H9, Jolion, M6×2)

## F7 (1 поколение) — https://www.drive2.ru/l/658635228780174559/
Способ через файл-флаг на флешке (НЕ через дозвон):
1. Флешку в FAT32, создать на ней ПУСТОЙ файл `svengmode.flag` (важно —
   расширение именно `.flag`, не `.txt`).
2. Вставить в ЛЕВЫЙ USB-порт магнитолы.
3. Откроется инженерное меню на китайском — найти нужный пункт (на
   скриншоте в оригинальном посте обведён, сам скриншот не считан) →
   выбрать "test device" → появится сообщение про извлечение USB — это
   нормально.
4. USB-A-USB-A кабель в ПРАВЫЙ порт, с компьютера: `adb devices`.
5. На экране магнитолы появится окно подтверждения → подтвердить →
   `adb devices` снова покажет устройство в списке.
6. Установка: скачать ARM64-версии APK → `adb install <путь_к_файлу.apk>`
7. Если обычная установка не идёт — `adb shell settings put global
   install_non_market_apps 1`, либо App Ops + Shizuku.
8. Возврат в обычный режим: `adb reboot` (или кнопка физического ресета).
⚠️ Перед визитом к дилеру — восстановить заводской лаунчер, `adb reboot
recovery`.
Также есть отдельный пост про F7 (2G, 2024) "Полный функционал ГУ" —
https://www.drive2.ru/l/698680816653314670/ — не считан подробно, вероятно
похожий/другой способ для нового поколения.

## M6 — ДВЕ модификации у нас ("2026" и "до 04.2026") — критично важно!
Источник проблемы 8-й прошивки: https://www.drive2.ru/b/719409909371782454/
⚠️ На M6 с прошивкой ВЕРСИИ 8 (соответствует нашей модификации "2026")
ADB включить НЕЛЬЗЯ вообще напрямую — нужно СНАЧАЛА откатить прошивку до
версии 7:
1. Флешка от 1 ГБ, отформатировать в NTFS.
2. Скачать файл прошивки (ссылка на Яндекс.Диск, не считана) — файл имеет
   расширение .iso, но это "какой-то китайский ISO" — архиваторами и
   программами работы с образами не откроется и выдаст ошибку — ЭТО
   НОРМАЛЬНО, не пугаться. Имя файла НЕ МЕНЯТЬ.
3. В машине: Настройки → Общие → Локальное обновление → вставить флешку →
   нажать "Обновить" в появившемся диалоге → дождаться перезагрузки.
4. После — система на версии 7, дальше обычные инструкции по установке
   Android Auto/CarPlay (в оригинальной статье, не процитированы здесь).

работать на машинах, где уже стояла версия 8! ОБЯЗАТЕЛЬНО предупредить
пользователя об этом в инструкции.
Другой M6 пост (Android Auto для чайников, 2023, вероятно "до 04.2026"):

## Общий метод входа в инженерное меню (из сводки поиска, применимо к части
моделей бренда)
Один из вариантов: несколько раз тапнуть по вкладкам "Display", "Volume",
"General" в определённой последовательности, ввести код `adayo2002`.
Другой вариант: один тап в левый нижний угол, затем сразу 10 раз в левый
верхний угол.

## Dargo — вход в меню найден, УСТАНОВКА ПРИЛОЖЕНИЙ ПОД ВОПРОСОМ

- https://www.drive2.ru/l/644187920869111028/ ("Установка приложений на ГУ")

- https://www.drive2.ru/l/663222666169171343/ ("Dargo GWMv3 Freeware")

Dargo, в отличие от Tank 300 (тот же код первых 2 уровней!), обычный

## H3 — подробный метод найден (тот же вход, что у части других Haval)
Источники:
- https://www.drive2.ru/l/722025922412164737/ (2025 год)
- https://www.drive2.ru/l/715130335238571235/ ("разблокировка + Яндекс")
- https://www.drive2.ru/l/715447819221094443/ ("Инструкция по прошивке
  Premium")
- https://www.drive2.ru/l/687871242962736053/ ("Расширенное меню")
- https://www.drive2.ru/l/685195856294457206/ (2024 год)
- tankhaval.ru/blog/proshivka-i-ustanovka-prilozheniy-na-multimedia-haval-h3-2024-2025
Вход: один тап в левый нижний угол → быстро 10 раз тапнуть в левый верхний
угол экрана (СОВПАДАЕТ с методом Tank 500 — см. research/Tank/notes.md —
ещё одно подтверждение общей платформы GWM/Great Wall).
После входа: раздел "Переключение режима USB" → выбрать "Peripheral".
Установка: подключить ноутбук, запустить программу **ADBAppControl**,
установить нужные приложения.
Кабель: USB A—USB A, один конец в ЛЕВЫЙ порт (со стороны водителя),
другой — в ноутбук.
Альтернативный вход (для более новых машин, если простой способ не
работает) — через диагностику Launch: Diagnostics → Great Wall → TANK →
TANK 500 → Fuel → System Selection → HUT (Navigation Host System) →
Special function → Set production mode → Factory mode → OK → перезагрузка
ГУ. (Обратите внимание: путь меню называется "TANK 500", хотя применяется
к Haval H3 — ещё одно подтверждение общей платформы между брендами Tank и
Haval).

## Общий вывод по Haval
Явно прослеживается ОБЩАЯ ПЛАТФОРМА между Haval (H3, H7, F7, возможно
Dargo/Jolion) и брендом Tank (300, 500) — совпадающие коды (`*#4435ab`/
`aZ10&*+30`), совпадающие жесты входа (10 тапов в угол), совпадающий путь
диагностики Launch ("GWM → Tank500 → HUT"). Это открывает возможность
переиспользовать бОльшую часть уже собранной информации по Tank для более
глубокого понимания Haval, и наоборот.
