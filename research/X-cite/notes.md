# X-cite (X-Cross 7, X-Cross 8)

⚠️ НИЧЕГО конкретного не найдено — поиск по прямому названию бренда/
моделей не дал ни одного релевантного результата (все ссылки оказались
про другие бренды: Zeekr, Chery Arrizo, Jaecoo J7, Exeed RX, Changan
Hunter).

Общий процесс, встречающийся почти везде и, вероятно, применим (но НЕ
подтверждено конкретно для X-cite):
1. Настройки → информация о системе → тапнуть несколько раз по строке
   версии → войти в инженерное меню.
2. В меню — найти переключатель "ADB" → включить (OPEN).
3. Подключить компьютер по USB → использовать ADB/скрипт установки.

## Следующий шаг
X-cite — редкий/малоизвестный бренд в России, возможно стоит:
- Поискать по алиасам: "Иксайт", "X-Cite Auto" (бренд по слухам —
  ребрендинг китайского OEM, могут быть посты под оригинальным китайским
  названием модели вместо "X-cite").
- Проверить, не является ли платформа общей с каким-то более известным
  китайским брендом (X-Cross 7/8 могут быть на платформе Chery/JAC/др. —
  стоит поискать технические обзоры машины, чтобы узнать производителя
  ГУ/платформы, и затем искать по имени этой платформы).
- Если ничего не находится — явно предупредить пользователя, что придётся
  либо ждать появления постов в интернете, либо действовать по аналогии
  с похожей платформой на свой страх и риск.
