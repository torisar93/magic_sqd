# Jetour (Dashing×2, T1, T2, X70 Plus, X90 Plus)

Есть отдельный сервисный сайт **jetour.tech/jetour** (платная услуга,
без техники) — покрывает Dashing (Android 9), T1, T2, X70 Plus (только
LUXURY), X90 Plus (только 2.0L) — подтверждает, что все эти модели
используют ПОХОЖУЮ платформу Android 9.

## X70 Plus — https://www.drive2.ru/l/712431309070288146/ (подробно, проверено)
1. Настройки → Система → тапнуть по "Версия головного блока" 6-7 раз.
2. Ввести код **`231215`** → OK → откроется сервисное меню (на китайском).
3. Слева — предпоследний пункт снизу.
4. Справа — "EngeneerMode" → Debug Util → Debug level → сменить с "User"
   на "CustomerEngeneer".
5. DAL Settings → включить тумблер "Enable DAL" (по умолчанию выключен).
6. Вернуться в главное меню → слева 6-й пункт снизу → справа 3-й пункт
   сверху → включить тумблер ADB.
7. Подключение: USB Type-C — USB-A, или USB-A—USB-A "папа-папа".
   Драйверы/утилиты — автор советует архив от Dashing (общий набор
   инструментов для всей платформы).
8. Дальше обычный `adb install`/`adb shell`.
⚠️ Пользователи отмечают трудности с выдачей полных разрешений
установленным приложениям — штатные настройки Android недоступны напрямую.
