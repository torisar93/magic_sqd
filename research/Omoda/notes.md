# Omoda (C5×2, C7)

## C5 — установка приложений через телефон (WiFi ADB, БЕЗ компьютера)
Источник: https://www.drive2.ru/b/675018501789849612/
⚠️ ВАЖНО: судя по всему на этой платформе **WiFi ADB уже включён по
умолчанию** — отдельного входа в инженерное меню/кода активации искать не
нужно (в отличие от большинства других брендов).
⚠️ "Лаунчер статичный! Приложения не появятся на экране, только через
сторонний лаунчер" — установленные приложения открываются в полноразмерном
окне, вылезающем за пределы боковых панелей, штатно неудобно пользоваться.

1. Раздать интернет с телефона, подключить магнитолу к этой Wi-Fi сети.
2. Приложение "Wi-Fi Monitor" на телефоне → раздел "DEVICES" → кнопка
   поиска → найти IP-адрес магнитолы (вида 192.168.10.10), сохранить.
3. Приложение "ADB" на телефоне → в верхнее поле вписать IP-адрес → кнопка
   подключения. Тумблер "Android 11-13" не трогать.
4. Скачать APK на телефон (архитектура ARM64/arm8a) — имя файла и путь
   ТОЛЬКО латиницей, без кириллицы и пробелов.
5. Через ES File Explorer — долгий тап по файлу → свойства → скопировать
   полный путь.
6. В приложении ADB → Terminal → `adb install -g <полный_путь>` (флаг `-g`
   выдаёт максимум разрешений сразу).
7. Доп. команды при необходимости:
   - `adb shell settings put global enable_freeform_support 1` (оконный
     режим)
   - `adb shell pm grant <package> android.permission.SYSTEM_ALERT_WINDOW`
     (окна поверх других приложений)
   - `adb shell monkey -p <package> 1` (запуск приложения)
8. Раздел "Tools" в ADB-приложении — скриншоты, разрешения, заморозка
   приложений, перезагрузка.
⚠️ SystemUI и голосовой ассистент Cerence иногда мешают отображению —
отключать только при необходимости, после отключения нужна перезагрузка.
Рекомендованное решение для юзабельности: приложение **Taskbar** (адаптация
Windows-подобной панели задач) — оконный режим произвольной формы.

## C5 (обе модификации "2026" и "до 2026") — НЕ различено
Метод выше не привязан явно к конкретному году/модификации — требуется
уточнить у пользователя/доп. поиском, отличается ли способ между "C5/2026"
и "C5/до 2026", или метод общий для обеих.

## C7 — инженерное меню найдено, установка приложений НЕ найдена
Источник: https://forumchery.ru/topic/6390-inzhenernoe-menyu-omoda-c7/
1. Настройки → раздел "settings" → тапнуть 7-10 раз в правом нижнем углу
   экрана.
2. Появится окно с VIN и временным кодом.
3. Ввести пароль (регистр ВАЖЕН!):
   - Рынок Казахстан (при коде "1234"): `1A2b3C4D@@`
   - Рынок Россия (при коде "1234"): `1A2b3c4d@@`
4. В меню — диагностика: версия ПО, обновления, тест экрана, GPS,
   микрофон, кнопки, динамики, батарея, системные логи.
⚠️ Не пытаться прошивать без официальных файлов — может заблокировать
систему.
⚠️ В этом источнике НЕТ информации про ADB/установку приложений — только
вход в меню. Т.к. WiFi ADB на платформе C5 уже включён по умолчанию (см.
выше), возможно на C7 то же самое — стоит проверить отдельно постом
"Как установить Android auto на Huawei — Omoda C7" (не считан):
https://www.drive2.ru/l/721052029987863086/
Также есть общий пост про Arrizo 8/Tiggo 8 Max/Omoda C5 (не C7):
https://www.drive2.ru/l/671760923714659822/
