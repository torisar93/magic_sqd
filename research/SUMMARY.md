# Итог ночного исследования (по состоянию на 2026-08-30 утро)

Собраны текстовые заметки с кодами/шагами/предупреждениями по каждой
модели каталога, сгруппированные по папкам `research/<Бренд>/`. Ссылки на
все источники сохранены внутри каждого файла.

⚠️ **ВАЖНЫЙ ПРОПУСК**: картинки/фото процесса установки НЕ скачаны — только
текстовые описания и ссылки на посты, где эти фото есть. Если нужно, могу
догрузить конкретные фото по выбранным моделям отдельным заходом (drive2
иногда режет прямой доступ к картинкам без просмотра самой страницы).

## Полностью готово (эти модели уже реализованы в приложении, для справки)
Belgee (все 5), Geely Emgrand/Tugella×2/Okavango, Knewstar 001,
Livan S6 Pro/X6 Pro.

## Подробно исследовано (коды/шаги найдены, конкретные предупреждения)
- **Changan** — все ~16 моделей (`research/Changan/notes.md`), через
  агрегатор hackchan.ru.
- **Geely** — Cityray×2, Monjaro×3 (`research/Geely/Monjaro.md`,
  `Cityray.md`) — отличные, детальные источники.
- **Jetour** X70 Plus (`research/Jetour/notes.md`) — остальные 5 моделей
  этого бренда — гипотеза по аналогии, не подтверждена.
- **Exeed** VX/рест и VX/дорест (`research/Exeed/notes.md`) — дорест
  оказался ТУПИКОМ (ADB отключён в прошивке намеренно).
- **GAC** GS8 обе модификации (`research/GAC/notes.md`).
- **Dongfeng** Aeolus Huge (`research/Dongfeng/notes.md`) — нужно
  подтвердить у пользователя, что это правильная модель.
- **Haval** F7(1 поколение), H7, H3, Jolion, M6 обе модификации
  (`research/Haval/notes.md`) — M6/2026 требует ОТКАТА прошивки с потерей
  камеры/парктроников, это критично для инструкции!
- **Tank 300** (`research/Tank/notes.md`) — простой путь с компьютера, без
  сканера.
- **Tenet T7** (`research/Tenet/notes.md`) — вычисляемый пароль.
- **Omoda C5** (`research/Omoda/notes.md`) — уникальный случай: WiFi ADB
  уже включён по умолчанию, вход через телефон вместо компьютера.

## Частично / требует доп. проверки
- **Chery** — Arrizo, Tiggo 4 Pro 2024, Tiggo 7 Pro Max/2023, Tiggo 9
  найдены; Tiggo 7 Pro Max/2024, Tiggo 7L, Tiggo 8 Pro Max — не тронуты.
- **Deepal** S07/SL03 — коды/меню найдены, но динамический код требует
  внешнего инструмента (не самостоятельно вычисляется).
- **Geely** Coolray (только для параллельного импорта, нестабильно),
  Atlas New/EX5/Preface — не найдены.
- **Tank** 500/700 — похоже, нужен ПРОФЕССИОНАЛЬНЫЙ диагностический
  сканер (DIAGZONE/AUTEL), а не просто компьютер — стоит уточнить с
  пользователем, входит ли это в охват приложения. Tank 400 не подтверждён
  отдельно.
- **Haval** Dargo (обычный ADB-путь, похоже, ЗАБЛОКИРОВАН, нужен более
  сложный кастомный метод), H5 (гипотеза по аналогии с H3, не
  подтверждена).
- **Voyah Free** — статический код `hellomotor` найден, но динамический
  пароль ВТОРОГО меню не расшифрован; Courage/Dreamer/Passion не найдены.
- **Omoda C7** — вход в меню найден, но установка приложений НЕ описана в
  источнике (WiFi ADB может быть уже включён, как у C5 — не проверено).
- **Soueast S09** — источник только про S07 (другая модель бренда),
  используется по аналогии, не подтверждено для S09.

## Слабо / почти не найдено
- **FAW** (B70/T77/T90/T99) — точных кодов нет ни для одной модели, но
  найден многообещающий след про T90 через адаптер Carlinkit TBox (проще
  обычного инженерного меню) — не считан подробно.
- **Jaecoo** (J6/J7/J8) — только общий контур метода, J6 ЯВНО отличается
  от J7 (нельзя копировать).
- **Wey 07** — не найдено напрямую, есть гипотеза об общей платформе с
  Tank 500/700 через 4PDA-тему (не проверена).
- **X-cite** X-Cross 7/8 — вообще ничего не нашлось, бренд слишком редкий
  для поиска по названию; возможно, стоит поискать по оригинальному
  китайскому названию платформы.

## Рекомендация по продолжению
Предлагаю продолжить "по одной" в порядке убывания готовности: сначала
модели из раздела "Подробно исследовано" (там уже почти готовые
инструкции), а слабые бренды (FAW, Jaecoo, Wey, X-cite, Tank 500/700)
доисследовать по ходу, когда дойдёт очередь.
