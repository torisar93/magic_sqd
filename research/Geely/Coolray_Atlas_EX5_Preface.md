# Geely Coolray, Atlas New, EX5-EX 5 EM-I, Preface

## Coolray — https://www.drive2.ru/l/667584978552358010/ (2023, парал. импорт)
⚠️ Работает ТОЛЬКО на машинах параллельного импорта (ПИ) — у официальных
дилерских (ОД) нет точки доступа Wi-Fi, нужной для установки этим
способом.
1. На Android-телефоне (не iPhone — придётся одолжить Android) скачать
   приложение с иконкой "божьей коровки" с Яндекс.Диска (ссылка в посте,
   не считана автоматически) — управляет магнитолой по Wi-Fi.
2. Войти в инженерное меню (по ссылке на другой пост автора — сам код не
   считан, нужен отдельный заход).
3. Найти кнопку "WIFI ADB" (подписана вперемешку с китайскими
   иероглифами, на скриншоте обведена красным).
4. Нажать её → подтвердить перезагрузку ("да" справа).
5. Включить точку доступа на телефоне, подключить к ней магнитолу.
6. Установить APK из архива по видео-инструкции (тоже на Яндекс.Диске).
   Начинать с Яндекс Карт.
7. ОБЯЗАТЕЛЬНО вернуться в меню и выключить WIFI ADB обратно — иначе
   потом флешки не будут читаться.
Проверено рабочее: Яндекс Навигатор/Карты, Яндекс Музыка, Кинопоиск.
⚠️ Автор отмечает нестабильность: приложения иногда падают, Wi-Fi
периодически отваливается, бывают сбои уведомлений.
Из поиска также упомянут отдельный код-формула по времени (как у
Belgee/Emgrand): `#*месяц+5 день часы` или `#*месяц+10 день часы` —
источник не сохранён точно, требует проверки — похоже на другую
модификацию/поколение Coolray (не тот же пост, что выше).
