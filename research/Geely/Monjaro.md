## Дальнейшие шаги (после входа в меню)
1. В открывшемся инженерном меню — выставить параметры, ПОКАЗАННЫЕ НА
   СКРИНШОТЕ (сам скриншот не считался текстовым разбором — нужно зайти
   на сайт живьём и посмотреть картинку).
2. Выключить ВСЕ переключатели (перевести влево) для корректной работы.
3. Подключить кабелем USB-A-USB-A к ноутбуку.
4. Запустить установочный скрипт для своей ОС:
   - Windows: скачать platform-tools или воспользоваться авто-скриптом
     сайта.
   - Mac: `brew install android-platform-tools` (через Homebrew).
   - Linux: скачать zip с platform-tools.
5. Следовать подсказкам в консоли скрипта.
6. После установки — открыть настройки MacroDroid и выдать ВСЕ нужные
   разрешения для корректной работы автоматизаций.

## Monjaro Starter Pack (MSP) — сам набор приложений в скрипте (~15 шт.)
Магазины приложений: Aurora Store, RuStore, Huawei AppGallery.
Системные инструменты: ES File Explorer, Google Chrome, Google-клавиатура.
Утилиты: MacroDroid (автоматизация), Яндекс.Диск, MenuButton (плавающая
кнопка навигации).
Доп. управление: Vivid (жесты), ShortcutMaker, приложения для пассажира.
Медиа: Monjaro Tweaks Lite (v1) или Monjaro Tweaks PRO (v2).
GPS-софт — для машин без встроенного GPS.
