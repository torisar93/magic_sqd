# Geely Cityray — ОТЛИЧНОЕ совпадение с нашими модификациями!

Источник: https://www.drive2.ru/l/731875072695865995/ (Android 11 HU)
Наш каталог: "Geely / Cityray / новая 2026 (без Wi-Fi, Monji)" и
"Geely / Cityray / не имеет доступа Wi-Fi (до 2026)" — ЭТО ТОЧНО ОНИ ЖЕ,
названия модификаций совпадают почти дословно с терминологией поста.

## Вход в инженерное меню (общий для обеих модификаций)
«Телефон» → набрать `#*32279`

## Способ для СТАРОЙ модификации (до 2026, "нет доступа Wi-Fi") — через telnet
(У НАС УЖЕ ЕСТЬ готовая инфраструктура telnet_adb.py в проекте — этот
способ ложится прямо на существующий механизм!)
1. Подготовить флешку FAT32 с нужными APK.
2. Включить точку доступа на магнитоле, подключить к ней комп/телефон.
3. Telnet: `telnet android.local` (или IPv6-вариант — как раз то, что
   умеет наш MdnsResolve/telnet_adb.py).
4. `cd /storage`
5. `pm install <имя_файла>.apk`
6. Разрешения — через приложение "Настройки" или командой.
Стартовый набор файлов: `GLauncherLink.apk` + `GInputBridge.apk` (лаунчер
+ управление вводом, парой), `FileManager.apk`, `Settings.apk`.

## Способ для НОВОЙ модификации (2026, вендор DesaySV, "Monji")
⚠️ Новая прошивка блокирует обычные ADB-команды установки на уровне ядра.
Два одобренных сообществом решения:
1. **GitHub-метод** — репозиторий MoskowKapik "AppInstaller" (bat-скрипты).
2. **Monji Team** — упрощённый графический интерфейс для автоматической
   установки (рекомендован для новичков — вероятно, ИМЕННО это имеется в
   виду в названии нашей модификации "..., Monji").
Оба способа требуют входа в НОВОЕ инженерное меню с подтверждением по
QR-коду, лог экспортируется на флешку.

## ⚠️ КРИТИЧЕСКИЕ ПРЕДУПРЕЖДЕНИЯ (обязательно включить в инструкцию!)
- НЕ НАЖИМАТЬ кнопку "Update" в инженерном меню — запускает Recovery
  Mode, из которого выход только через разрядку аккумулятора.
- Отключение/остановка системных приложений может НАВСЕГДА вывести ГУ из
  строя (кирпич).
- Перед обращением по гарантии — сбросить к заводским настройкам, иначе
  могут отказать в гарантии.

## Что ещё нужно
- Найти сам GitHub-репозиторий MoskowKapik/AppInstaller и посмотреть на
  Monji Team инструмент — на сайте drive2 пост, скорее всего, даёт прямые
  ссылки, которые текстовый разбор не сохранил.
- Скриншоты (GLauncher, GSplit, SCS-климат, Android Auto, навигация по
