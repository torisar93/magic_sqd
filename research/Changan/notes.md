# Changan — механизм подписи APK (реверс-инжиниринг ChanganInstall, 2026-08-30)

⚠️ КРИТИЧЕСКИ ВАЖНО для ВСЕХ моделей Changan/суббрендов ниже: обычный
"adb install"/"pm install" произвольного APK на прошивках WutongOS
(梧桐车联, платформа Changan+Tencent) **не проходит** — платформа проверяет
serial number сертификата, которым подписан APK, против жёстко зашитого в
прошивке белого списка. Само содержимое сертификата (issuer/subject) НЕ
проверяется — только числовой serial, подтверждено дважды на практике:
`changan_tweaker.apk` (официальное приложение от Changan, сертификат
`CN=Ben, OU=AIS, O=Changan`) и наш собственноручно сгенерированный
сертификат (`CN=SCM, OU=Software, O=WTCL`) с ОДИНАКОВЫМ serial ставились
одинаково успешно.

Платный сторонний сервис **ChanganInstall** (`changaninstall.ru`,
`client_win_x64/ChanganInstall.exe`) просто переподписывает любой
скормленный APK нужным сертификатом на своём сервере и возвращает назад —
больше НИЧЕГО не делает (побайтовое сравнение подтвердило: единственная
разница между исходным и обработанным APK — файлы `META-INF/`, весь код и
ресурсы идентичны). Механизм уже реализован в самом проекте (не нужно
ничего платить/слать на их сервер):
- `app/apk_signer.py` (desktop) + `android/.../ApkResign.kt` (Android,
  библиотека Google `apksig`) — переподписывают APK автоматически перед
  установкой, если у модели есть `files/resign_cert/{private.pk8,
  certificate.crt}`.
- Оба файла сертификата можно как найти готовыми (см. Lamore ниже), так и
  сгенерировать самому — команды (проверено, работает):
  ```
  openssl genrsa -out private.key 2048
  openssl req -new -key private.key -out csr.csr -subj "/emailAddress=auto_release@auto-pai.com/CN=SCM/OU=Software/O=WTCL/L=HaiDian/ST=Beijing/C=CN"
  openssl x509 -req -in csr.csr -signkey private.key -out certificate.crt -days 18250 -set_serial 0xXXXXXXXXXXXXXXXX
  openssl pkcs8 -topk8 -nocrypt -in private.key -outform DER -out private.pk8
  ```
  (serial — см. таблицу ниже; certificate.crt из openssl уже в нужном PEM
  для apksigner/apksig, private.pk8 — то, что реально нужно, private.key
  выбрасывается).

✅ **Oshan X5 Plus** — динамический пароль полностью разобран (тот же
JS-бандл hackchan.ru, компонент `D` на странице модели):
```js
let h = date.getHours() % 12; if (h === 0) h = 12;
let m = 10 * Math.floor(date.getMinutes() / 10);
password = pad2(m) + pad2(h);   // например 20:03 → "0008"
```
То есть 2 цифры минут (округлённые вниз до десятков) + 2 цифры часа в
12-часовом формате (0 часов/полдень → 12). Проверено вживую: в 20:03 MSK
формула и живая страница hackchan.ru совпали (обе дали `0008`). Встроено
в `Oshan X5 Plus/files/instruction_1/instruction.html` как живой
JS-калькулятор (обновляется раз в секунду, без сети — компонент
достаточно посчитать в браузере техника, который использует то же
локальное время, что и магнитола).

## Как добывать serial для ещё не проверенных моделей (без реальной
машины) — рецепт, полностью отработанный в этой сессии:
1. `devtools/fake_adb_device.py` (или собранный `.exe`) — эмулирует ADB-
   устройство по TCP, отвечает на конкретные getprop/settings команды
   заданными строками (см. сам файл за полным списком того, что реально
   спрашивает ChanganInstall: `getprop ro.serialno/ro.build.display.id/
   ro.build.version.release/ro.build.cpu.abilist/ro.product.cpu.abilist`,
   `settings --user 0 get system ca.car.tuid/ca.car.vin`, `cat /sys/
   class/block/mmcblk0/device/cid`, `which su`, `df -h`, несколько `ls -la`
   — на всё это нужно ответить хоть чем-то, иначе ChanganInstall не
   опознает "устройство").
2. Подставляя РАЗНЫЕ строки в `ro.build.display.id` (полный список
   найденных в бинарнике ChanganInstall.exe кандидатов — есть в истории
   сессии/памяти агента) — ChanganInstall опознаёт РАЗНЫЕ модели Changan.
   Перед каждой новой попыткой обязательно удалить
   `client_win_x64/huData.json` — иначе программа "помнит" предыдущее
   устройство и не показывает заново идентификацию/выбор модели.
3. Как только модель опознана — скормить любой безобидный тестовый APK,
   посмотреть, каким файлом он вернулся в "папку для файлов"
   `fake_adb_device.exe`, вытащить `META-INF/*.RSA` (имя файла — по alias
   ключа, не всегда `CERT.RSA`) и посмотреть serial:
   `openssl pkcs7 -inform DER -in ЧТО-ТО.RSA -print_certs -text`.
4. Если пакет пришёл с ЧУЖОЙ подписью (не self-signed WTCL/AIS, а
   например `C=RU, O=RuStore`) — значит этот конкретный APK не
   переподписывался вообще (уже доверенное приложение), serial из него
   узнать нельзя — нужно смотреть на apk, который ТОЧНО прошёл через их
   переподпись (свой собственный тестовый файл — самый надёжный вариант).

# Changan — источник: hackchan.ru

Целый сайт https://hackchan.ru посвящён именно Changan (плюс Deepal/Oshan —
суббренды на тех же платформах) — это браузерный ADB-установщик, но на
каждой странице модели есть и сам способ входа в инженерное меню текстом.
Это НАМНОГО эффективнее, чем искать каждую модель по отдельности на
drive2 — почти весь бренд закрывается этим одним сайтом.

Дисклеймер сайта (на каждой странице): "Все действия на сайте вы совершаете
на свой страх и риск. Установка приложений может стать причиной снятия ГУ
автомобиля с гарантии."

## Alsvin — https://hackchan.ru/changan/alsvin/
Метод: **USB, без инженерного меню**. Скачать нужные .apk на флешку,
установить через встроенный файловый браузер магнитолы. Характеристики ГУ
неизвестны на сайте.

## CS35 Plus New — https://hackchan.ru/changan/cs35plusnew/
Метод: ADB.
1. «Телефон» → набрать `***#*#888**` → Вызов
2. Пароль `369875`
3. Второй пункт слева в инженерном меню → кнопка ADB
⚠️ Важно: на ГУ ~1 ГБ памяти под приложения — НЕ ставить тяжёлые/кэширующие
(например Яндекс Навигатор) — предупреждение, что переполнение может
привести к отказу запуска системы и потребовать ремонта.

## CS75 Plus — https://hackchan.ru/changan/cs75plus/ (два поколения, вкладки)
Характеристики: Android 9, Allwinner T7 (6-core Cortex-A7), RAM 3 Gb.
- **Поколение 1 (ОД)** — соответствует нашей модификации "1-3 поколения":
  «Телефон» → `*#201302#*` → после последней `*` все цифры на экране
  пропадут — это нормально, готово.
- **Поколение 3 (2024)** — соответствует нашей модификации "4 поколение":
  «Телефон» → `*#20228888#*` → откроется инженерное меню → пункт 7
  «调试工具» (debug tools) → кнопка ADB.

## EADO Plus — https://hackchan.ru/changan/eadoplus/
Android 9, Allwinner QUAD-CORE t7 p1, RAM 2 Gb.
«Телефон» → `*#201301#*` → «Automated test» слева → «connect adb».
Доп. коды, упомянутые на странице: `*#518121#*` (включить ADB напрямую?),
`*#518120#*` (сброс USB-порта) — не до конца ясно, как именно
используются, нужна проверка живьём.

## Hunter Plus — https://hackchan.ru/changan/hunter/

## Oshan X5 Plus — https://hackchan.ru/oshan/oshan-x5plus/
«Телефон» → `***#*#888**` → Вызов → пароль, который "меняется каждые 10
минут" → в инженерном меню пароль `3821` → кнопка ADB в левом верхнем углу.
Проверил живьём в момент 06:06 (мск) страница показывала пароль **0006**
— похоже на формулу «минуты, округлённые вниз до десятков (2 цифры) +
текущий час, 24-формат (2 цифры)» (00 + 06 = 0006), но это ГИПОТЕЗА по
одному замеру, не подтверждено вторым замером в другое время — нужно
перепроверить перед тем, как класть в реальную инструкцию (лучше сверить
ещё раз через 10-20 минут и увидеть, что изменилось именно так).

# Deepal (суббренд Changan, но отдельная марка у нас в каталоге)

## Deepal S07 / S7 S07 — https://hackchan.ru/deepal/deepal-s7/
Android 11, Qualcomm sa8155p, RAM 8 Gb, ROM 128 Gb. Установка через
разблокировку системы (НЕ обычный дозвон-код), способ ОДИНАКОВЫЙ для
вкладок OS 2.X и OS 1.X (только получение кода отличается, судя по всему,
самой прошивкой):
1. Около 10 раз тапнуть по часам в правом верхнем углу экрана магнитолы.
2. В появившемся окошке ввести код — **код меняется КАЖДЫЙ ДЕНЬ**, и,
   судя по формулировке "введите ПОЛУЧЕННЫЙ код", берётся откуда-то
   ИЗВНЕ (скорее всего с самого сайта hackchan.ru после "подключения"
   машины через их сервис, а не считается по простой формуле на глаз, как
   у Belgee/Geely Emgrand) — то есть без их сайта/бота этот путь
   самостоятельно не пройти, если не найдём формулу отдельно.
Также на странице: русский язык уже есть "из коробки" в прошивке, скрыт в
настройках языка внутри инженерного меню; есть отдельная тема про
обновление прошивки до 3.0 с флешки (без выпайки SIM).
Доп. источник (drive2, без деталей): https://www.drive2.ru/l/725266458057117430/
— ссылается на китайский инструмент deepal.yukiovo.com ("набор эффективных
инструментов для Deepal, снимающих ограничения на установку в один клик"),
плюс отдельно Bilibili-видео для Deepal S05 (Rustore → нужные программы
из Rustore). Официальных скриншотов процесса нигде не нашлось.
⚠️ Deepal — самый сложный случай из всех Changan-моделей, нужен
отдельный, более глубокий заход (возможно с самим пользователем, если он
знает про сервис deepal.yukiovo.com или подписан на hackchan в Telegram).
