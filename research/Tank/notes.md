# Tank (300, 400, 500, 700)

## Tank 300 — ПОДРОБНО, проверенный рецепт
Источник: https://www.drive2.ru/l/665594862506104553/
(есть более новая "Сборка version 3" того же автора — вероятно обновлённый
набор приложений, тот же вход в меню: https://www.drive2.ru/l/670500608511328609/;
плюс отдельный пост "Прошивка ГУ Tank 300: установка приложений, навигации
и онлайн кино" — не считан подробно: https://www.drive2.ru/l/714889817070000357/)

### Вход в инженерное меню
1. Настройки → Информация о системе (System Information).
2. Быстро тапнуть НЕСКОЛЬКО раз по строке "Software Version" → появится
   запрос пароля → ввести **`*#4435ab`** → откроется первое инженерное
   меню.
3. В этом меню быстро тапнуть по строке "HW Version" → запрос пароля →
   ввести **`aZ10&*+30`** → откроется РАСШИРЕННОЕ инженерное меню.
4. В левом меню найти раздел "Others" → переключить USB-режим на
   **"peripheral"** (периферийное устройство) — это нужно для распознавания
   компьютером по USB.

### Установка приложений (с компьютера)
5. Подключить магнитолу к компьютеру кабелем USB-A—USB-A. Windows покажет
   уведомление о новом устройстве.
6. Win+R → `cmd` → командная строка.
7. `pushd <путь_к_папке_с_приложениями>` (пример из поста:
   `pushd D:\TANK300\T300_applications_by_Augusto_v3`).
8. Запустить `start.bat` — поднимает ADB-мост.
9. Запустить `install.bat` — спрашивает по каждому приложению
   `y` (установить) / `n` (пропустить).
Без перепрошивки, без постоянных изменений в ГУ (по словам автора).

## Tank 500 — вход в БАЗОВОЕ меню найден, ПОЛНОЕ меню — сложнее
Источник: https://www.drive2.ru/b/669600658243979397/
Также отдельный пост "Установка APK на ГУ" (не считан подробно):
https://www.drive2.ru/l/693055165409806576/, и "Устарело — Установка
приложений в наше ГУ Tank 500": https://www.drive2.ru/l/669553928999807676/

### Базовое меню (10+ строк)
1. Один тап в левый нижний угол (под иконкой "домой").
2. Быстро 10 раз тапнуть в левый верхний угол (над иконкой приложений) —
   может потребоваться несколько попыток.
3. Появится всплывающее окно про сертификат/USB-флешку → тапнуть по нему.

### ПОЛНОЕ инженерное меню — 3 способа (ни один не через простой код!)
- **DIAGZONE** (сканер + адаптер): GWM (кастомизировано) → Tank500 → HUT →
  Special functions → Production mode. Нужна активная подписка. ⚠️ Автор
  отмечает, что СЕЙЧАС этот метод НЕ РАБОТАЕТ (проблемы с онлайн-сервисом).
- **AUTEL** (планшетный диагностический сканер): тот же путь в меню,
  подтверждено рабочим.
- Некоторые машины УЖЕ приезжают с полным меню включённым (от дилера).
⚠️ Значит для Tank 500, в отличие от 300, нужен ПРОФЕССИОНАЛЬНЫЙ
диагностический сканер (не обычный компьютер) — это выше обычного уровня
нашей инструкции, стоит явно предупредить пользователя / уточнить,
насколько это реалистично для нашей аудитории.

## Tank 400 — отдельно не найдено, упоминается только в одном заголовке
4PDA-тема с общим покрытием ("ШГУ TANK 500, 400, 700, Haval H3, F7, H7, H9,
WEY07"): https://4pda.to/forum/index.php?showtopic=1110681 — судя по
заголовку, все эти модели используют ОДНУ и ту же платформу ГУ и,
вероятно, схожий метод — стоит зайти на саму тему форума и прочитать
подробно (WebFetch не пробовал — форумные темы часто требуют браузер).

## Tank 700 — метод похож на 300/500 (сканер + USB peripheral режим)
Источники: та же 4PDA-тема, плюс общие посты Tank 300/500 выше.
1. Открыть ПОЛНОЕ инженерное меню через сканер (упоминается просто
   "scanner (hut, special - factory mode)" — вероятно тот же DIAGZONE/AUTEL
   путь, что у 500).
2. После перезагрузки в инженерном меню — сменить режим USB с host на
   peripheral.
3. Подключить ноутбук USB-A—USB-A кабелем, использовать приложение
   AdbAppControl для подключения к ГУ.
4. Установка — вручную через ADB/cmd-команды, либо готовым скриптом
   установки.
⚠️ Предупреждение из источника: "Installing third-party applications
without understanding could result in losing the head unit" (можно
"убить" магнитолу, если делать не понимая).
⚠️ Установленные приложения появляются в штатном лаунчере ТОЛЬКО на
прошивке F7 и выше с активированными сервисами Yandex — на более старых
прошивках лаунчер их может не показывать.

## Общий вывод по бренду Tank
Все 4 модели используют РАЗНЫЕ по сложности методы: 300 — просто код с
компьютера; 500/700 — предположительно нужен профессиональный
диагностический сканер (DIAGZONE/AUTEL); 400 — не подтверждено отдельно.
Перед тем как строить реальную инструкцию, нужно уточнить у пользователя,
готовы ли мы предполагать наличие сканера у клиента для 500/700, или это
вне охвата приложения.
