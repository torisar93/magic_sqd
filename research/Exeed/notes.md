# Exeed

## VX / рест (2024, рестайлинг) — https://www.drive2.ru/b/672695233720365762/
1. Настройки → раздел с информацией о хранилище (памяти).
2. Несколько раз тапнуть по значению объёма памяти → откроется
   инженерный режим, запросит пароль.
3. Пароль: **`20242024`**
4. В программе AdbAppControl (на компьютере) в консоли выполнить команду:
   `adb setprop persist.sv.enable_adb_install 1`
5. Подключение: ноутбук (Windows) — кабель USB Type-C — Exeed VX.
6. AdbAppControl → после синхронизации вкладка "Приложения" → "Установка"
   → "Быстрая установка" → выбрать APK.
⚠️ Известные ограничения: официальный YouTube не работает (нужен
"remaster"-сборка), маскот интерфейса может закрывать кнопки входа/игр,
игры нельзя вывести на пассажирский экран, выход из игр — только кнопкой
"звезда" на руле.

  выше), у старых поколений встроенного ADB нет вовсе.
