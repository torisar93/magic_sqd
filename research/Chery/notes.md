# Chery — заметки (нет единого сайта-агрегатора, как hackchan у Changan)

Общее по бренду: почти везде используется классический путь "инженерное
меню → ADB → комп с ADB AppControl → USB-A-USB-A кабель → APK". Почти
каждый пост советует ставить сначала RuStore и дальше через него, а ADB
выключать обратно после установки (иначе флешки не читаются нормально).

## Arrizo (наша модель — сверить, что за поколение) — https://www.drive2.ru/l/671504462627479480/ (Arrizo 8)
1. В разделе информации о версии — тапать под иконкой машины, пока не
   появится меню.
2. Пароль ВЫЧИСЛЯЕМЫЙ по ID устройства: берём последние 7 цифр ID
   устройства → умножаем на `802018` → последние 6 цифр результата — это
   код доступа. (Формула специфична для конкретной единицы техники, не
   одна и та же для всех машин!)
3. Внутри инженерного меню — включить Wi-Fi, подключиться к точке доступа
   телефона.
4. Настройки системы → нажать кнопку "лог/статус" 5 раз подряд → выбрать
   пункт "adb" → включить отладку.
5. ПК: ADB AppControl + USB-A-USB-A кабель → установка APK.
⚠️ Автор пишет "карты и ютуб не работают" — проблемы совместимости с
некоторыми приложениями на этой версии Android.
⚠️ Нужно уточнить: наш каталог просто "Arrizo" — это статья про Arrizo 8,
надо сверить совпадает ли головное устройство с тем, что имеет в виду
пользователь.

## Tiggo 4 Pro 2024 — https://www.drive2.ru/l/701703374118066940/
Инженерное меню — необычное расположение: раздел "Хранилище/System-Disk",
тапать через разные пункты (автор пишет "китайцы решили просто положить
это сюда" — без точной пошаговой последовательности тапов). Внутри —
переключатель ADB, включить.
⚠️ После установки — ОБЯЗАТЕЛЬНО выключить ADB обратно, иначе USB-флешки
потом не распознаются.
ПК: ADB APP Control, кабель USB-A (USB Type-C — не проверено автором).
Полезные команды из поста:
- `adb shell dumpsys package ru.yandex.yandexnavi | grep Activity` — узнать активность приложения
- `adb shell am start --display 0 -n com.example.app/.MainActivity` — запустить приложение
Совет автора: сначала поставить только RuStore, остальное — уже через него.

## Tiggo 7 Pro Max (2023) — https://www.drive2.ru/l/685215372625850287/
СОВСЕМ другой путь — ФИЗИЧЕСКИЙ USB-порт для отладки за бардачком, без
кодов инженерного меню вообще:
1. Снять бардачок, открутить левое крепление.
2. За панелью — блок головного устройства с двумя портами, заклеенными
   плёнкой.
3. Подключиться USB-кабелем (лучше Г-образным разъёмом, автор потратил
   ~1.5 часа из-за тесноты и плохой видимости) ко ВТОРОМУ порту (со
   стороны пассажира).
4. Дальше обычный ADB с компьютера.
Автор ссылается на видео-инструкцию, которую не процитировали в посте.
⚠️ Для 2024 года "Tiggo 7 Pro Max" в нашем каталоге ЕСТЬ отдельная
модификация — не проверено, тот же способ или другой, нужен отдельный
поиск конкретно под 2024.

## Tiggo 9 — https://www.drive2.ru/l/704450229042172357/
1. Если интерфейс на китайском — сначала переключить язык на английский.
2. Зайти в самый нижний пункт настроек.
3. 10 раз тапнуть по верхней панели → откроется инженерное меню.
4. Найти "USB2.0 AUTH" → нажать подсвеченную кнопку → включится ADB.
Инженерное меню также даёт: точный расход топлива в литрах (бак 64 л),
статус батареи, тесты динамиков/радио/GPS/экрана/камеры водителя.
⚠️ По комментариям — на новых прошивках ADB из меню УБРАЛИ. Работало на
прошивке 02.01.00, после обновлений могло пропасть — нужно уточнять
версию прошивки у пользователя.
