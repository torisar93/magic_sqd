Категория "Плееры" — общая для всех марок/моделей.

Положите сюда .apk аудио/видео плееров — они появятся отдельной группой на
этапе "Выбор приложений" в мастере "Установка", под этим же названием.
Правила именования/описания — те же, что и для apk/README.txt (необязательный
<файл>.json рядом с APK, с полями "name"/"description").
