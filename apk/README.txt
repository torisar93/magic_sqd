Общая папка стандартных приложений.

Просто положите сюда .apk файлы — они автоматически появятся в приложении
как галочки в разделе "Стандартные приложения" для любой модели.

Необязательно: чтобы задать красивое имя и описание, создайте рядом с APK
файл с тем же именем и расширением .json, например:

  yandex_navigator.apk
  yandex_navigator.json

Содержимое yandex_navigator.json:
{
  "name": "Яндекс Навигатор",
  "description": "Актуальная версия на 2026 год, без рекламы карт"
}

Без .json файла в списке просто будет показано имя файла.
