Перед началом
Если вы еще ничего не устанавливали на свое ГУ, то перед началом работ вам НЕОБХОДИМО выполнить процедуру отключения и очистки логов ГУ.

Если вы уже что-то устанавливали, но не выполняли процедуру отключения логов, то НЕОБХОДИМО её выполнить, а после этого настоятельно рекомендуется удалить всё, что было установлено. Для этого в инструкциях по установке, как правило, есть отдельный bat-файл. Также, можно полностью удалить установленные ранее приложения установкой 7-ой версии прошивки поверх своей. В этом случае, процедуру отключения логов нужно произвести после установки прошивки.

Если у вас прошивка 8-ой версии, то вам необходимо выполнить откат до 7-ой версии, а затем выполнить процедуру отключения и очистки логов.

Крайне рекомендуется использовать для установки компьютер с ОС Windows 10 или 11. В более низкие версии Windows необходимо будет устанавливать драйвер для корректной работы с ADB.

Скачиваем архив и распаковываем его в корень диска C. У вас должно получиться C:\lazymod.

Процесс
Шаг 1. Расширение доступной памяти ГУ.
Подключаемся к ГУ по ADB (см. инструкцию для чайников). Запускаем файл LazyMod.bat из папки C:\lazymod\platform-tools. Для проверки успешного подключения ГУ к компьютеру выбираем пункт 1. Проверить соединенние с ГУ по ADB и нажимем Enter. Если ошибки нет и ГУ успешно подключено, выбираем пункт 2. Расширение доступной памяти и нажимаем Enter. Ждём, процесс занимает некоторое время. По завершении процесса ГУ перезагрузится. Нажимаем любую клавишу и возвращаемся в меню, выполнение скрипта расширения памяти закончено.

Если в ходе проверки подключения к ГУ получили ошибку, то ещё раз проверяем всё ли сделали правильно по "инструкции для чайников".

Шаг 2. Разблокировка установки приложении и установка базового пакета.
Подключаемся к ГУ по ADB (после шага 1 нужно будет отключить кабель от компьютера на время входа в инжененрное меню и подключить обратно после включения ADB). Для проверки успешного подключения ГУ к компьютеру выбираем пункт 1. Проверить соединенние с ГУ по ADB и нажимем Enter. Если ошибки нет и ГУ успешно подключено, выбираем пункт 3. Разблокировка установки приложений и установка стартового пакета и нажимаем Enter. Скрипт установит на ГУ следующие приложения: File Manager, панель запуска приложений Edge Screen, кнопку Назад и иконку доступа к системным настройкам Android. По завершении работы скрипта на экране ГУ запустится File Manager. Перейдите в раздел Программы, запустите приложение Edge Screen и обязательно активируйте переключатель Включить сервис в правом верхнем углу.

Если всё сделали правильно, то с правой стороны экрана у вас появится тонкая сине-зеленая полоска, при клике на которую будет открываться панель быстрого запуска приложений Edge Screen. В неё нужно добавить иконки для запуска File Manager, Настройки (бело-серые шестеренки) и самого EdgeScreen. В неё же, в дальнейшем нужно будет добавлять иконки для запуска всех остальных установленных приложений.

Перед началом установки приложений с флешки вам нужно переключить порт ГУ из режима ADB в обычный. Это можно сделать перегрузив магнитолу долгим нажатием на ручку регулировки громкости или через соответствующий пункт меню.

Шаг 3. Установка Viper FX (Viper4Android).
Подключаемся к ГУ по ADB (нужно будет отключить кабель от компьютера на время входа в инжененрное меню и подключить обратно после включения ADB). Для проверки успешного подключения ГУ к компьютеру выбираем пункт 1. Проверить соединенние с ГУ по ADB и нажимем Enter. Если ошибки нет и ГУ успешно подключено, выбираем пункт 6. Установка Viper FX и нажимаем Enter. Скрипт установит на ГУ драйвер, библиотеки эффектов и само приложение Viper FX. По завершении работы скрипта перезагрузите ГУ. Для запуска и настроек добавьте иконку Viper FX в панель запуска Edge Screen.

По завершении вы получите:
Увеличение объема доступной для программ и данных памяти.

Возможность установки приложений с флешки через File Manager, без необходимости подключать компьютер по ADB.

Приложение Viper FX для улучшения звучания.
