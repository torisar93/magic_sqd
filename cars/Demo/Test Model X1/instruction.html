Это демо-инструкция. Скопируйте эту папку как шаблон для реальной модели.

Это пример оформления. Реальные шаги и скриншоты для конкретной магнитолы нужно заменить на актуальные — фото меню, точные названия пунктов и т.д.

1. Вход в инженерное меню

  1. На главном экране откройте Настройки → О системе.
  2. Нажмите 7 раз на пункт «Версия сборки», пока не появится сообщение «Вы стали разработчиком».
  3. Вернитесь назад — в настройках появится новый пункт «Для разработчиков».

2. Включение отладки по USB

  1. Откройте Настройки → Для разработчиков.
  2. Включите переключатель «Отладка по USB».
  3. Если есть пункт «Отладка по USB (настройки безопасности)» — включите и его.

3. Подключение и проверка

  1. Подключите магнитолу к ноутбуку по USB (или используйте ADB по Wi-Fi, если модель не имеет прямого USB-порта для ПК).
  2. На экране магнитолы подтвердите запрос «Разрешить отладку по USB» и поставьте галочку «Всегда разрешать с этого компьютера».
  3. В приложении нажмите «Обновить список устройств» — модель должна появиться в списке со статусом device.
