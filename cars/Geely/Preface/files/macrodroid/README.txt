MacroDroid + Helper и данные для импорта (раньше C:\GAAI\Apps\MDpro\ и
atlas.category / Wheel_button_.category рядом с bat-файлом). Положите сюда:
  - основной APK MacroDroid (например MacroDroid.apk)
  - APK хелпера — определяется по имени файла, в котором есть "helper"
    или "mdh" (например MDH_v1.14.apk подходит как есть)
  - *.category (и/или Script.zip) — импортируются на магнитолу автоматически
