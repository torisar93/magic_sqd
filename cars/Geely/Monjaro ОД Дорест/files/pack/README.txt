Сюда положите APK Monjaro Starter Pack (раньше лежали в папке Pack\ рядом
с adb_install.bat). Все .apk из этой папки появляются отдельными галочками
("Стандартные приложения") на этапе "Выбор приложений" мастера "Установка"
— по умолчанию отмечены, ставятся все вместе с "Дополнительными
приложениями" на следующем этапе.

Необязательно: чтобы задать красивое имя и описание вместо имени файла,
создайте рядом с APK файл с тем же именем и расширением .json — формат тот
же, что и в apk/README.txt:
{
  "name": "Красивое имя",
  "description": "Короткое описание"
}
